## 🐛 TROUBLESHOOTING

### **Problem: No Notification**

**Check:**
```
1. Notifications enabled in app? (ON)
2. Browser permission granted? (Allow)
3. Time set correctly? (check time picker)
4. Time hasn't passed yet? (wait until time)
5. Browser tab closed? (keep open or minimized)
```

**Fix:**
```
1. Check settings
2. Re-enable notifications
3. Allow browser permissions
4. Set time in future
5. Wait for notification
```

### **Problem: Wrong Time**

**Check:**
```
1. Time picker shows correct time?
2. 24-hour format? (08:00 = 8 AM)
3. Time zone correct? (device time)
4. Not in past? (must be future time)
```

**Fix:**
```
1. Click time picker
2. Select new time
3. Confirm change
4. Wait until that time
```

### **Problem: Browser Permission**

**Check:**
```
1. Did you click "Allow"?
2. Or did you click "Deny"?
3. Is it still showing permission prompt?
```

**Fix:**
```
Method 1: Click "Allow" in prompt
Method 2: Browser settings → Notifications → Allow

Then:
1. Refresh page
2. Enable notifications again
3. Now it should work ✅
```
