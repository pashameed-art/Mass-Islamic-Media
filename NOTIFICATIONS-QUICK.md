# 🔔 Daily Notifications - Quick Start

**Enable Reminders in 30 Seconds!**

---

## ⚡ QUICK SETUP

### **Step 1: Settings**
```
Bottom Nav → ⚙️ Settings
```

### **Step 2: Enable**
```
🔔 Daily Dua Notification
Toggle: ON
```

### **Step 3: Set Time (Optional)**
```
Default: 08:00 (8 AM)
Click time to change
Save automatically ✅
```

### **Step 4: Allow Permission**
```
Browser asks: "Allow notifications?"
Click: "Allow"
Done! ✅
```

---

## ✅ WHAT YOU GET

```
📬 Daily reminder at your set time
🕌 Shows: "Daily Dua 🕌"
📖 Content: Dua title + description
🔄 Repeats every day automatically
```

## 🐛 TROUBLESHOOTING

### **No Notification?**

```
Check:
1. Enabled in Settings? ✓
2. Browser permission allowed? ✓
3. Correct time set? ✓
4. Device time correct? ✓
5. Still waiting for time? ✓

All good? Should work now! ✅
```

### **Browser Permission Prompt**

```
If asked: "Allow notifications?"
Click: "Allow" ✓

If missed:
1. Browser settings
2. Find "Notifications" permission
3. Select "Allow" for this website
4. Refresh page
5. Try again ✅
```
